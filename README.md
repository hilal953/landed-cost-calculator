# Landed Cost Calculator

A local-first web app designed to calculate the true landed cost (in LKR) of imported auto parts from China (in RMB) for Matara-based businesses.

## Features
- **Local First**: Everything saves automatically to your browser.
- **Auto-Mapping**: Drop in your standard supplier Excel packing list and it automatically finds the Qty and Price columns.
- **Default Profiles**: Pre-loaded with standard Sri Lankan import fees.
- **Export Ready**: One-click "Copy to Excel" to paste directly into your POS.
